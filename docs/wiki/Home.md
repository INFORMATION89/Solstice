# Solstice

**Solstice is an Android weather app designed to help people prepare for the day without drowning them in weather data.**

It focuses on the information that changes what you do: how warm it will feel, when rain may arrive, what the next hours look like, when conditions are better for going outside, and what to wear.

## What Solstice is building

- **A useful forecast:** current conditions, actual temperature and feels-like temperature, hourly and daily forecasts.
- **A clear outlook:** what is coming next, the best time to be outside, and notable weather over the coming days.
- **Practical guidance:** concise clothing, rain, and sun-protection advice based on forecast evidence.
- **Places:** current location and saved places, with local time where it differs.
- **Weather context:** precipitation, UV, air quality, wind, and official warnings when reliable source data is available.

Solstice aims to be proactive without being intrusive. Essential weather works without an account; location and notification permissions are requested only when the related feature needs them.

## Project status

Solstice is in active pre-release development. The first stable public release is planned as **1.0.0**, after a staged Alpha and Beta.

The rolling GitHub `testing` build is a development/testing channel. It is **not** the public Alpha or a stable release. No public release dates have been committed yet.
